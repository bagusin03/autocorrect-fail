Good Luck On Your Exorcism: one line, a single autocorrect fail, for make.fun's "Funniest Autocorrect Fail" bounty. `main.ts` writes a single 133-character line to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard enforces the gate (1–199 characters, one line, not only whitespace) before writing, and the written bytes are read back and verified.

> I meant to text my friend 'Good luck on your exam!' but autocorrect sent 'Good luck on your exorcism!' She's still not talking to me.

## Run it

```sh
node main.ts
```
